# سرگذشت ماندگار

یک وب‌اپلیکیشن فارسی و راست‌به‌چپ برای آشنایی تعاملی با چهره‌های برجسته تاریخ، علم، هنر و فلسفه.

## امکانات

- جستجوی فارسی و نرمال‌سازی حروف عربی/فارسی
- فیلتر بر اساس دسته‌بندی
- صفحه جزئیات هر شخصیت
- نشان‌کردن چهره‌ها با `localStorage`
- مسابقه چندگزینه‌ای
- خط زمان
- انتخاب تصادفی چهره
- خواندن نقل‌قول با Web Speech API
- طراحی Mobile-first و RTL

## اجرا

فایل `index.html` را در مرورگر باز کنید. برای انتشار، پروژه را روی GitHub Pages یا هر سرویس میزبانی استاتیک قرار دهید.

> تصاویر و داده‌های زندگی‌نامه‌ای برای نسخه نمایشی هستند و پیش از انتشار عمومی بهتر است از نظر منبع و دقت تاریخی بازبینی شوند.
